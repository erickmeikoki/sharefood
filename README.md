# ShareFood - Community Food Sharing Platform

## Overview
ShareFood is a community-driven food sharing platform that simplifies local food redistribution through innovative and user-friendly technology. This platform allows users to quickly share surplus food with their local community, reducing food waste and fostering community connections.

## Live Demo
🌐 **Deployed Application:** [https://food-share-app.replit.app/)

## Key Features
- **No Authentication Required**: Simple, accessible interface with no login barriers
- **Image Uploads**: Upload up to 5 images per food listing with carousel display
- **Favorites System**: Save listings to your favorites for later reference
- **Advanced Search & Filtering**: Filter by category, search terms, and favorites
- **Social Sharing**: Share listings on social media platforms
- **Responsive Design**: Mobile-friendly interface that works on all devices

## Tech Stack
- Frontend: React with Vite, TailwindCSS, Shadcn/UI
- Backend: Express.js
- Database: PostgreSQL with Drizzle ORM
- Deployment: Replit

## Getting Started
1. Clone this repository: `git clone https://github.com/erickmeikoki/shareFood.git`
2. Install dependencies: `npm install`
3. Set up your PostgreSQL database and update the `.env` file with your database connection string
4. Run database migrations: `npm run db:push`
5. Seed the database: `npm run db:seed`
6. Start the development server: `npm run dev`
